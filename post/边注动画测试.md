# 边注与 Markdown 动画测试

这是一篇仅用于本地开发的草稿。正文中的脚注编号应该被手绘圆圈标记，并连接到左侧边注。[^short]

## Markdown 强调动画

这句话包含 **粗体强调文字**，旁边还有 *斜体补充文字*。它们进入视口时应保留原有样式，同时出现手绘下划线。

这句话包含 ~~准备删除的内容~~，应在原删除线之外出现手绘 crossed-off 动画。

> 引用块保留主题原有样式，同时在右侧绘制手绘括号。动画只播放一次，避免滚动时持续干扰阅读。

## 多个脚注与碰撞

这段文字包含一个较长的脚注，用来验证多行边注、链接以及连接线的位置。[^long]

两个引用靠得很近时，左侧边注应该自动向下排列，不应互相覆盖。[^near-one] 紧接着是另一个脚注。[^near-two]

## 响应式检查

在宽度不小于 1440px 时，脚注显示在正文左侧；缩窄浏览器后，左侧边注消失，点击脚注编号应显示浮层。文章底部不应出现可见的脚注列表。

[^short]: 这是一条简短边注，用于确认基础位置和手绘连接线。
[^long]: 这是一条较长边注，其中包含 [Rough Notation](https://roughnotation.com/) 链接，用于测试多行内容、外部链接和边注卡片高度。
[^near-one]: 第一条相邻边注，用于测试自动防碰撞布局。
[^near-two]: 第二条相邻边注；它应该排列在上一条边注下方，同时仍与自己的正文编号对应。
